Entry for make.fun bounty **The Houseplant Out-of-Office**
($2, winner takes all): one line, at most 120 characters, the funniest
out-of-office auto-reply a houseplant would send, judged pairwise
by a house judge.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> Out of office: not watered since March. If your email is urgent, pour it on my roots — it's the only attention I get.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
